# 🛍️ Analyzing Customer Shopping Behavior

## 📌 Project Overview

A data analytics project analyzing **3,900 customer shopping records** to understand purchasing behavior, revenue patterns, product performance, discounts, subscriptions, repeat purchases, and customer segments.

The project follows an end-to-end workflow:

**Python → Data Cleaning → MySQL → SQL Analysis → Power BI Dashboard**

---

## 🛠️ Technologies Used

- **Python**
- **Pandas**
- **NumPy**
- **MySQL**
- **SQL**
- **Power BI**
- **Jupyter Notebook**

---

## 🧹 Data Preparation

The dataset initially contains **3,900 records and 18 columns**.

Python was used to:

- Import and inspect the dataset
- Identify missing values
- Handle missing `Review Rating` values using category-wise median
- Standardize column names
- Create an `Age_group` column
- Convert purchase frequency into day-based values
- Remove the redundant `Promo_Code_Used` column
- Rename `Purchase_Amount_(USD)` to `Purchase_Amount`
- Load the processed dataset into MySQL

---

## 🗄️ SQL Analysis

The project answers **10 business questions**, including:

1. Revenue generated by male vs. female customers
2. Customers using discounts who spent above the average purchase amount
3. Top 5 products by average review rating
4. Comparison of Standard vs. Express shipping purchase amounts
5. Subscriber vs. non-subscriber spending and revenue
6. Products with the highest percentage of discounted purchases
7. New, Returning, and Loyal customer segmentation
8. Top 3 products within each category
9. Subscription behavior of repeat buyers
10. Revenue contribution by age group

- Customer demographics
