# Project Overview

A data analytics project analyzing 3,900 customer shopping records to understand purchasing behavior, revenue patterns, product performance, discounts, subscriptions, repeat purchases, and customer segments.

The project follows an end-to-end workflow:-
Python → Data Cleaning → MySQL → SQL Analysis → Power BI Dashboard

# Technologies Used
--> Python
--> Pandas
--> NumPy
--> MySQL
--> Power BI
--> Jupyter Notebook

# Data Preparation
The dataset initially contains 3,900 records and 18 columns.

Python was used to:
Import and inspect the dataset
Identify missing values
Handle missing Review Rating values using category-wise median
Standardize column names
Create Age_group
Convert purchase frequency into day-based values
Remove redundant Promo_Code_Used
Rename Purchase_Amount_(USD) to Purchase_Amount
Load the processed dataset into MySQL

# SQL Analysis
The project answers 10 business questions, including:	

Revenue generated by male vs. female customers
Customers using discounts who spent above average
Top 5 products by average review rating
Standard vs. Express shipping purchase amounts
Subscriber vs. non-subscriber spending and revenue
Products with the highest discount purchase percentage
New, Returning, and Loyal customer segmentation
Top 3 products within each category
Subscription behavior of repeat buyers
Revenue contribution by age group

# Objective

The main objective of this project is to demonstrate an end-to-end data analytics workflow—from raw customer data cleaning and database preparation to SQL-based business analysis and interactive Power BI visualization.
